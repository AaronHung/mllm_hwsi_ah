# WP2 implementation and fairness audit

**Contract:** v0.292 under direction freeze v0.32  
**Date:** 2026-08-15  
**Scope:** frozen `can_dataset` main/reverse CSVs and the implementation
used to produce them. No model or dataset rerun was performed.

## Audit verdict

**No materially unfair implementation was found.** The existing Protocol-v1
grids remain usable as frozen evidence. Two interpretation limits are recorded:

1. `joint` is a joint-training reference with a different update schedule; it
   is not an upper-bound claim.
2. `ours` and `ours_uniform` share utility-prioritized buffer truncation, so
   their ablation isolates utility weighting in the distillation loss, not the
   full effect of utility-aware memory.

## Metric definitions

The implementation in `scripts/aggregate_results.py` is the authoritative
aggregation:

- **Forgetting:** for each old task `j`, `max(bal_acc at any stage from j
  through the final stage) - final bal_acc`. The reported value is the mean
  over old tasks. This is max-past-to-final, not simply own-stage-to-final.
- **BWT:** for each old task `j`, `final bal_acc - bal_acc at the task's own
  stage`; then mean over old tasks. Positive BWT is backward improvement.
- **Jaccard:** selection sets are paired by the same slide ID between the
  task's own-stage trajectory and its final-stage trajectory:
  `|A ∩ B| / |A ∪ B|`. It is a set metric, so action order is intentionally
  discarded.
- **Action-KL:** `nav.cl.kl_drift(pi_ref, pi_now)` computes
  `KL(pi_ref || pi_now)` using `F.kl_div(log(pi_now), pi_ref)`, averaged over
  the same probe states. The reference is the task-boundary policy and the
  current distribution is the final policy.
- **AA:** mean final-stage balanced accuracy over tasks.

The paper and reports must use these exact definitions and the direction
arrows in the tables: AA/BWT/Jaccard higher is better; Forgetting/action-KL
lower is better.

## Update counts and loss scale

Evidence from `scripts/cl_main.py` and `nav/cl.py`:

- `can_dataset` uses evaluator epochs = 30 and navigator epochs = 10.
- For sequential methods, each stage performs exactly
  `10 × len(current-task teacher steps)` optimizer updates.
- Each replay-enabled update samples exactly **one** state uniformly from the
  flattened old-task buffer. It does not iterate over the whole buffer.
- The buffer first keeps two teacher states per slide and, if over capacity,
  keeps the globally highest-utility states up to the cap. This composition is
  shared by `replay`, `distill`, `ours_uniform`, and `ours`.
- Every candidate-level KL uses `reduction="sum"` rather than a
  candidate-count mean. The current-task teacher loss is always present.
  `replay` adds one counterfactual-teacher target loss; `distill` adds one
  old-policy KL; `ours_uniform` adds both at λ=1 with uniform weight; `ours`
  adds both with the normalized, clipped utility weight.
- The utility weight is `utility / mean(buffer utility)`, clipped at 5. It is
  not applied to the counterfactual replay-target loss.

Thus the compared sequential methods have the same current-task update count
and at most one sampled replay state per update. Their loss objectives differ
as intended by the method definitions; this is not an accidental extra epoch.

## Joint-training reference

At stage `t`, `joint` concatenates teacher states from all tasks seen so far
and trains for the same 10 epochs over that concatenated set. Consequently its
number of optimizer updates grows with the number of seen tasks. This is a
reference for mixed-task training, not a compute-matched continual-learning
baseline and not an upper bound. The paper should state this explicitly.

## Reverse `K=1` distill standard deviation

The five frozen reverse-order seed-level aggregates for `distill`, `K=1`,
are:

```text
Forgetting: 0.019200, 0.013833, 0.008833, 0.011500, 0.016167
mean = 0.013907, sample std = 0.004021, range = 0.010367
```

The reported `std ≈ 0.004` is therefore a normal five-seed sample standard
deviation, not a degenerate zero-variance or aggregation artifact. The same
rows have non-zero variation in AA (std 0.015809), Jaccard (0.029839), and
action-KL (0.010417). No rerun is justified.

## Naming and scope corrections

For paper-facing text, use:

- `distill`: old-policy / policy-fidelity distillation;
- `replay`: counterfactual-teacher replay;
- `ours_uniform`: replay + policy distillation, uniform loss weight;
- `ours`: Utility-Weighted Replay Distillation, a variant;
- `joint`: joint-training reference.

Do not call `distill` exact-action preservation, `joint` an upper bound, or
`ours` a universal winner. WP3 observes λ=3 own-time degradation in 4/8
matched task×K cells, so a qualified stability–plasticity phrase is allowed
for those cells; retain **behavior-fidelity / capability-retention
trade-off** as the broader claim and do not imply a universal monotonic law.
